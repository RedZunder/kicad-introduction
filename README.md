# kicad-introduction
This repository stores all necessary files for the Introduction to Electronic Design 101 with KiCAD, on 2nd June 2026.

The file [jlpcb_rules](./jlpcb_rules/jlpcb_rules.kicad_pcb) contains the constraints given by JLPCB's manufacturing capabilities, as well as default trace and via sizes.

The trace sizes have been calculated using this [trace width calculator](https://nick.desmith.net/Electronics/TraceWidth.html).

The items in the [icons](./icons) folder contains free sample logos to add to the board, for testing. You can of course add your own.
[sample_code](./sample_code) contains an example code for the ATTINY85 to match the functionality of the PCB.
